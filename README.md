# Telegram Content Bot
Build: `pip install -r requirements.txt`
Start: `python bot.py`

هر /newpost متن فارسی دوستانه و خلاقانه با قلاب ذهنی، متن نسبتاً طولانی، @nova_ip، سؤال از اعضا و هشتگ‌های مرتبط می‌سازد و برای هر پست یک تصویر اختصاصی تولید می‌کند.
متغیرها: TELEGRAM_BOT_TOKEN, TELEGRAM_CHANNEL_ID, OPENAI_API_KEY, OPENAI_TEXT_MODEL=gpt-5.6-luna, OPENAI_IMAGE_MODEL=gpt-image-2
نکته: تولید تصویر مصرف API دارد و ممکن است هزینه OpenAI داشته باشد.
